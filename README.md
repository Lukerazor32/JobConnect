# JobConnect — Telegram-бот для поиска работы

Бот, который сам ищет вакансии и присылает новые прямо в Telegram. Пользователь задаёт город и категорию, а бот периодически опрашивает job-площадки и уведомляет, когда появляется что-то подходящее. Данные тянутся через официальные API **SuperJob** (с OAuth-авторизацией) и **Habr Career**.

## Что умеет

- Поиск вакансий по городу и категории через API SuperJob и Habr Career
- Подписка на новые вакансии — бот сам проверяет обновления по расписанию и присылает свежие
- Создание и хранение резюме пользователя, авторизация в SuperJob по OAuth
- Пошаговый диалог с ботом на конечном автомате (у каждого пользователя своё состояние)

## Технологии

- **Java 17**, **Spring Boot** (Web, Data JPA)
- **PostgreSQL** + **Hibernate**, миграции через **Flyway**
- **Telegram Bots API** (telegrambots-spring-boot-starter)
- HTTP-клиент **Unirest** для запросов к внешним API, JSoup и json-path для разбора ответов
- **JUnit** — юнит-тесты команд и интеграционные тесты репозиториев
- **Docker** / Docker Compose, **CI на GitHub Actions** (сборка и тесты на каждый push)

## Как это устроено

- **Command pattern** — каждая команда бота (`/start`, поиск, подписка, резюме) вынесена в отдельный класс, все регистрируются через общий контейнер
- **State machine** — диалог ведётся по состояниям (ввод города, выбор категории, подтверждение), для каждого пользователя своё
- **Слой сервисов и репозиториев** — отдельно бизнес-логика (поиск, авторизация, работа с резюме) и доступ к БД через Spring Data JPA
- Периодический опрос новых вакансий вынесен в фоновую задачу по расписанию

## Запуск

```bash
# 1. Скопировать шаблон переменных окружения и заполнить своими значениями
cp .env.example .env

# 2. Поднять приложение и базу
docker compose up --build
```

Нужные переменные (в `.env`): токен бота от @BotFather, `id` и secret-key приложения SuperJob, доступы к БД. Все секреты читаются из окружения — в коде их нет.
